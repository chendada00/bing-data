数据说明

这个仓库不仅保存图片，同时保存壁纸的结构化数据和颜色分析结果。

月度 JSON

完整壁纸数据按照年份和月份保存。 每个月对应一个 JSON 文件，例如：

/data/2026/09.json

月度数据包含日期、标题、描述、版权信息、 图片地址、预览图以及颜色分析数据。

历史索引

data/index.json 是轻量级历史搜索索引。 它主要保存日期、标题和描述， 用来避免搜索历史数据时一次性加载所有月度 JSON。

/data/index.json

图片资源

图片和 JSON 数据分开保存。 前端通常优先使用 preview， 进入详情页后再根据需要加载原图。

/preview/YYYY/MM/YYYY-MM-DD.jpg
/images/YYYY/MM/YYYY-MM-DD.jpg

颜色数据

每张图片会保存主要颜色信息， 可以用于页面主色展示、颜色筛选以及后续颜色相关功能。

color
colorHistogram

Color Histogram：颜色直方图

当前项目的 colorHistogram 使用 HSV 颜色空间进行统计。 当前版本将色相、饱和度、明度划分为：

Hue：12 个区间
Saturation：3 个区间
Value：3 个区间

12 × 3 × 3 = 108 个颜色区域
注意：颜色直方图不是图片地图

直方图中的每一个 bin 表示一类 HSV 颜色区域中包含的像素数量。 它描述的是整张图片的颜色组成，而不是像素在图片中的空间位置。

因此，如果详情页以后展示一个由 12 × 3 × 3 组成的大方格，左上角并不对应原图片的左上角。 它代表的是某一个特定的 HSV 颜色区间。

鼠标悬停在颜色区域上时，可以进一步显示： 色相区间、饱和度区间、明度区间、像素数量以及占整张图片的比例。

数据更新流程

数据通过自动化脚本获取 Bing 每日壁纸， 生成预览图和颜色分析，然后更新月度 JSON 以及历史索引。

Bing ↓ 获取壁纸 ↓ 保存原图 ↓ 生成 Preview ↓ 颜色分析 ↓ 更新月度 JSON ↓ 更新 index.json
