项目说明

前端、结构化数据与 UHD 图片分开管理，各仓库职责独立。

月度 JSON 与历史索引

每个月的壁纸数据保存在单独的 JSON 文件中。 data/index.json 提供轻量级历史索引， 前端可以先检索索引，再按需加载月份数据。

/data/index.json

图片地址分离

预览图片服务于日常浏览，UHD 图片服务于高清查看和下载。 两种图片分别部署在不同的仓库及域名中。

https://bing-data.伴随.cn/preview/YYYY/MM/YYYY-MM-DD.jpg
https://bing-uhd.伴随.cn/images/YYYY/MM/YYYY-MM-DD.jpg

颜色直方图

colorHistogram 使用 HSV 颜色空间统计整张图片的颜色组成。 当前划分为 Hue 12 个区间、Saturation 3 个区间、Value 3 个区间， 共 12 × 3 × 3 = 108 个颜色区域。 每个区域表示一种颜色区间，而不是图片中的空间坐标。
